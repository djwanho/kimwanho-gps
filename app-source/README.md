# 김완호 GPS 통합 도보 길안내 v1.5.5 — 방향 부채꼴 + 즐겨찾기

기준 소스: v1.5.3 GPX 파일 선택·도보 내비게이션 수정 버전.
**제작자 김완호 / © 2026 김완호.**

## v1.5.5 변경 사항
- 음성 내비게이션 전체화면에서 현재 GPS 파란 점 앞에 반투명 **방향 부채꼴** 표시
  - 걷는 속도가 약 0.9m/s 이상일 때 GPS 이동 방향을 우선 사용
  - 정지 중에는 갤럭시 나침반 센서를 사용
  - 센서 미지원·방향값 없음은 부채꼴을 숨김 (임의 방향을 만들지 않음)
  - 정확한 도로 안내 방향이나 GPS 오차 범위를 보증하는 표시는 아님
- **지도를 길게 눌러** '꾹 누른 지점 저장' 또는 '내 현재 GPS 위치 저장' 선택
- 즐겨찾기 이름 입력 및 로컬 저장 (앱 재실행 후에도 유지), 최대 200개
- 지도에 즐겨찾기 별 마커 표시
- 상단 별 버튼과 전체화면의 별 버튼을 눌러 목록 열기
- 즐겨찾기를 선택하면 목적지 지정 → 도보 경로 자동 조회
- 목록에서 즐겨찾기 삭제
- v1.5.3 GPX·주소·GPS 입력, 한국어 TTS, 현재 GPS 추적 유지

## 준비
- Flutter SDK, Android Studio
- 기존 APK와 같은 `com.kimwanho.gpswalknavigator` 패키지명
- 기존 **릴리스 서명키**를 유지해야 사용자 APK 위에 업데이트 설치 가능

## 실행 및 APK 생성
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

### 서명 주의
`android/key.properties`가 누락되면 릴리스 서명이 구성되지 않거나 기존 앱과 서명이 달라질 수 있습니다.
개발자 본인의 기존 서명키와 `key.properties`를 설정하고 APK 서명과 버전코드 증가를 확인하세요.
기존 앱 백업 후 실기기에서 업데이트 설치를 시험하세요.

### 설치 후 필수 시험
1. 목적지 설정, 파란 경로, 한국어 음성 시작 → 전체화면 확인
2. 제자리에서 갤럭시를 돌려 부채꼴이 회전하는지 확인
3. 기기를 들고 몇 걸음 이동할 때 GPS 진행방향에 맞게 부채꼴 갱신 확인
4. 지도 빈 곳을 꾹 누름 → 누른 지점/현재 GPS 위치 선택 → 이름 저장
5. 앱 완전 종료 후 재실행 → 즐겨찾기 별 마커/목록 유지 확인
6. 목록에서 목적지로 지정 → 도보 경로 조회 → 음성 시작
7. 목록에서 삭제 후 재시작하여 삭제 유지 확인
8. GPX 파일 불러오기·주소 검색·위치 추적 기존 기능 회귀 시험
9. 나침반 없는 기기에서 오류 없이 현재위치 점은 표시되는지 확인

## 운영·개인정보
- 즐겨찾기 이름과 좌표는 휴대폰 내부 환경설정에 저장됩니다.
  휴대폰 또는 앱 데이터 삭제 시 사라질 수 있습니다.
- 보행 경로 조회 시 현재위치와 목적지가 기존 Valhalla 외부 서버에 전송됩니다.
- 공개 배포 전 개인정보 처리방침에도 **로컬 즐겨찾기 저장·삭제** 설명을 추가하세요.
- Google Maps의 공식 부채꼴이 아니라 Flutter 지도에 자체 렌더링한 방향 표시입니다.
- 이 환경에는 Flutter/Android SDK가 없어 **실제 APK 빌드와 갤럭시 기기 테스트는 미실행**입니다.
- 운영 중인 홈페이지 APK는 실기기 검사 성공 후 변경하세요.

자세한 배포 순서는 `CODEX_UPDATE_REQUEST.md` 참고.
