주요 기능

출발 전 입력부터 걷는 동안 안내까지

복잡한 설정 없이 목적지를 지정하고, 앱 안에서 경로와 음성안내를 이어서 사용할 수 있습니다.

01

주소·좌표 통합 검색

도로명 주소, 위도·경도, 도분초(DMS), GPX 좌표 문자열을 인식합니다.

02

GPS 파일 불러오기

GPX·CSV·TXT 파일에서 첫 지점 또는 마지막 지점을 목적지로 선택합니다.

03

실시간 현재 위치

앱 사용 중의 GPS 위치를 지도에 표시하고 전체화면 안내에서 따라갑니다.

04

도보 경로와 예상 시간

Valhalla 보행 경로를 지도에 그리고 거리와 예상 소요 시간을 보여줍니다.

05

한국어 음성안내

갤럭시의 한국어 TTS 엔진을 사용해 경로의 회전 지점을 안내합니다.

06

전체화면 길안내

음성안내를 시작하면 경로 중심의 전체화면 지도로 전환됩니다.

07

현재 방향 부채꼴

전체화면 음성안내 중 현재 위치에서 바라보거나 이동하는 방향을 파란색 부채꼴로 표시합니다.

08

장소 즐겨찾기

지도를 길게 눌러 장소를 저장하고, 재실행 후에도 불러와 목적지로 지정하거나 삭제할 수 있습니다.

09

작은 지도 창(PIP)

음성안내 중 홈 화면으로 이동해도 Android 시스템 PIP 창에서 지도와 다음 안내를 확인할 수 있습니다.

10

백그라운드 GPS 안내

음성안내가 활성화된 동안 알림을 표시하고 화면 전환 후에도 GPS와 한국어 음성안내를 이어갑니다.

11

자동 경로 재탐색

정확한 GPS가 경로에서 30m 이상 벗어난 상태로 연속 확인되면 현재 위치에서 도보 경로를 다시 계산합니다.

사용 방법

화면에 보이는 순서대로 4단계

  1. 1

    목적지를 입력하세요

    목적지 (주소 · GPS · 위도/경도) 칸에 주소 또는 좌표를 입력합니다. 복사한 값은 붙여넣기, 파일은 GPS 파일 불러오기를 누르세요.

  2. 2

    목적지 설정을 누르세요

    주소 검색 결과의 좌표를 확인한 뒤 목적지 지정을 누릅니다. 좌표 입력은 바로 목적지로 설정됩니다.

  3. 3

    앱 안에 도보 경로 표시

    현재 GPS가 확인되면 앱 안에 도보 경로 표시를 누릅니다. 지도에 경로와 거리·예상 시간이 나타납니다.

  4. 4

    한국어 음성안내 시작

    경로가 준비된 뒤 버튼이 활성화됩니다. 누르면 현재 위치를 다시 확인하고 전체화면 지도로 안내합니다. 별도 앱이 필요하면 구글 지도에서 열기를 사용하세요.

음성이 들리지 않나요?앱의 마이크 권한은 필요하지 않습니다. 갤럭시 설정에서 한국어 TTS 음성과 미디어 음량을 확인하고, 앱의 음성 테스트 아이콘을 눌러보세요.

갤럭시 설치 방법

보안 기능 전체를 끄지 않아도 됩니다

APK를 연 앱에 대해서만 필요한 설치 권한을 허용하세요. 메뉴 이름은 One UI 버전에 따라 조금 다를 수 있습니다.

  1. APK 다운로드위의 다운로드 버튼을 누릅니다.
  2. 내 파일에서 찾기갤럭시의 내 파일 → 다운로드에서 APK를 누릅니다.
  3. 보안 안내 확인설치 차단 안내가 나오면 안내 화면의 설정으로 이동합니다.
  4. 이 출처 허용APK를 연 앱(내 파일·Chrome·Drive 등)에 한해 이 출처 허용을 켜고 돌아옵니다.
  5. 설치 및 실행설치를 누른 뒤 완료되면 앱을 엽니다.
  6. 위치 권한 허용요청이 나오면 앱 사용 중에만 허용 등 필요한 범위를 확인해 선택합니다.
  7. 목적지와 음성안내목적지를 설정하고 도보 경로를 표시한 뒤 한국어 음성안내를 시작합니다.
설치가 계속 차단되면

회사·학교 단말의 관리 정책, 보호자 설정 또는 기기 보안 정책 때문일 수 있습니다. 보안 기능 전체를 무조건 해제하지 말고 단말 관리자에게 확인하세요.

기존 앱을 업데이트하나요?

이 홈페이지에서 받은 공식 v1.5.1 또는 v1.5.4는 삭제하지 않고 v1.5.6을 바로 설치할 수 있습니다. 디버그·테스트 APK는 인증서가 달라 업데이트가 되지 않을 수 있으므로 필요한 정보를 확인한 뒤 테스트판을 삭제하고 공식 APK를 설치하세요.

데이터와 안전

어디로 무엇이 전송되는지

경로 조회·재탐색

경로 조회 시 현재 위치와 목적지 좌표가 FOSSGIS가 운영하는 Valhalla 공개 데모 서버로 전송됩니다. 음성안내 중 경로 이탈이 확인되면 자동 재탐색을 위해 다시 전송될 수 있습니다.

지도·주소

표시 영역의 지도 타일은 OpenStreetMap 서버에서 받고, 주소 검색은 Android 기기의 지오코딩 서비스를 이용합니다.

기기 안 처리

GPX·CSV·TXT 내용과 한국어 TTS 안내는 기기에서 처리합니다. 즐겨찾기 이름과 좌표는 휴대폰에 저장되며, 앱 자체에는 계정이나 이동 기록 저장 기능이 없습니다.

Valhalla와 OpenStreetMap 공개 서비스는 가용성이 보장되지 않고 공정 사용·사용량 제한이 적용될 수 있습니다. 대량 조회나 오프라인 지도 다운로드 기능은 제공하지 않습니다.
