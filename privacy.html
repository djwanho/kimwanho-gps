1. 앱이 처리하는 정보

앱은 사용자가 기능을 실행할 때 다음 정보를 처리합니다.

  • 정밀 또는 대략적 위치: 현재 위치 표시, 도보 경로 조회 및 음성안내를 위해 Android 위치 권한으로 가져옵니다.
  • 목적지 정보: 사용자가 입력한 주소, 위도·경도 또는 선택한 GPS 파일의 지점을 처리합니다.
  • GPS 파일: 사용자가 직접 선택한 GPX·CSV·TXT 파일을 기기에서 읽어 목적지 후보를 찾습니다.

2. 외부 서비스로 전송되는 정보

Valhalla 공개 데모 경로 서버사용자가 도보 경로 조회 또는 음성안내 시작을 누르면 현재 위치와 목적지의 위도·경도가 valhalla1.openstreetmap.de로 전송됩니다. 요청에는 앱 식별자 com.kimwanho.gpswalknavigator가 포함됩니다.
OpenStreetMap 타일 서버지도 표시를 위해 현재 보고 있는 지도 영역·확대 수준에 해당하는 타일을 tile.openstreetmap.org에서 요청합니다. 이 과정에서 통상적인 네트워크 정보(IP 주소, User-Agent 등)가 서버에 전달될 수 있습니다.
Android 지오코딩 서비스주소를 좌표로 변환할 때 Android 기기가 제공하는 지오코딩 서비스를 이용합니다. 기기·서비스 제공자의 설정에 따라 주소와 네트워크 정보가 외부 서버에서 처리될 수 있습니다.

3. 기기 안에서 처리되는 정보

GPS 파일 분석과 한국어 음성 합성(TTS)은 기기에서 처리됩니다. 이 앱 자체에는 회원가입, 사용자 계정, 광고 SDK, 분석 SDK, 위치 기록 또는 검색 기록을 별도 서버에 저장하는 기능이 없습니다. 위치 추적은 앱이 화면에 표시되어 사용하는 동안에만 이루어집니다.

4. 보관·삭제

앱 개발자는 앱을 통해 계정·위치 기록을 수집하거나 자체 서버에 보관하지 않습니다. 앱 입력값과 경로 상태는 앱 실행 중 메모리에서 사용됩니다. 앱을 종료하거나 앱 데이터를 삭제하면 앱 내부 상태가 제거됩니다. 외부 서비스의 접속 로그와 보관 기간은 각 서비스 운영자의 정책이 적용됩니다.

5. 권한과 선택권

위치 권한을 거부하거나 Android 설정에서 철회할 수 있습니다. 다만 현재 위치 기반 경로·음성안내는 사용할 수 없습니다. 주소 대신 좌표를 직접 입력할 수 있습니다. 권한은 갤럭시의 설정 → 애플리케이션 → 김완호 GPS 통합 길안내 → 권한에서 변경할 수 있습니다.

제작자: 김완호. 확인되지 않은 이메일·전화번호는 기재하지 않았습니다. 앱 또는 개인정보 관련 문의는 GitHub Issues를 이용할 수 있습니다. 공개 게시판이므로 민감한 개인정보는 작성하지 마세요. 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신합니다.
